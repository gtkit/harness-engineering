# TypeScript MCP 安全

工具参数、roots、资源 URI、外部文本和下游响应都是不可信输入。参数 schema 合法不等于有权访问；每次操作按已认证主体和实际资源授权，不把最后一次请求的 token、目录或租户存成共享默认值。

## 文件、命令与网络

- 读取、创建、覆盖、删除分别授权。路径检查针对最终资源，覆盖 `..`、相邻前缀、大小写、符号链接/硬链接及 TOCTOU；`path.resolve` 或字符串 startsWith 本身不能证明访问受限。
- 压缩包限制输入与展开大小、条目数、单项大小、深度和耗时；拒绝危险条目、设备文件及越界链接。预检不能替代实际写入约束。
- 临时文件和提交路径有明确归属，默认不覆盖用户产物；失败/取消清理不删除其他请求的数据。提交后清理失败与未提交失败分别返回。
- 外部命令使用受信可执行路径与参数数组，禁止拼接 shell 或 `shell: true` 处理用户参数；参数本身也要防选项注入。限制环境、cwd、时长、输出并回收进程树。
- 出站请求限制 scheme、主机、端口、DNS/IP、代理和每次重定向；阻止未经授权的内网、loopback、link-local 与云元数据访问。确需内网采用业务 allowlist。
- 响应 body、解压后大小、重试、分页、并发和总时间有界；下游提供的新 URL 不自动继承信任。

## JavaScript 边界

外部对象不得无约束深合并到配置或原型链；验证危险键、属性归属和 schema。限制正则、JSON 嵌套、同步压缩及 CPU 工作，避免事件循环拒绝服务。不能通过类型断言绕过权限或输入校验。

## 凭据与 OAuth

令牌验证目标资源、签发方、有效期、scope 和算法。禁止将客户端发给 MCP 的 token 直接透传给上游；下游使用独立授权凭据。授权发现、JWKS、重定向、PKCE 和缓存轮换按所选标准实现，不无限抓取未知 kid。[授权安全规范](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization/security-considerations)

秘密不进源码、npm 包、source map、日志、URL 或工具结果；不用全量 process.env 排障。npm lifecycle script 是代码执行边界，安装前确认来源与副作用。

越权、跨主体泄漏、路径/链接、命令参数、SSRF、超大输入与取消需针对性验证；mock 不能证明真实 OS 权限或上游授权。客户端确认、工具注解与服务端权限互不替代。
