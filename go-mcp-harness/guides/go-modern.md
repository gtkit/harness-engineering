# Go 版本与现代写法

通用语言知识由 `use-modern-go` 维护，不在本 harness 复制一份易过时的语法手册。

1. 从项目 `go.mod`、toolchain、构建标签和实际本机 Go 读取版本；未核实前不引用新标准库 API 或语法。
2. 按当前会话中的真实技能位置读取 `use-modern-go`，只读适用于项目版本的 references。技能缺失时用该版本官方文档核实，不猜默认安装路径。
3. 现代化服从行为等价、接口兼容、取消和资源释放语义；不因新写法可用而批量改无关代码。
4. `go fix`、modern 检查、vet、lint 和质量门禁均按主入口授权边界执行；不得因技能默认步骤自动运行。
5. 引入新 Go 最低版本、升级依赖主版本或首次 `/v2` 模块都需要明确范围和兼容方案，不由 harness 代为决定。
