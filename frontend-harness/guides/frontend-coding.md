# 前端编码 Guide

- 组件通过 props/emits 定义边界，避免修改 props 和共享对象；派生值不复制到 state。
- 外部 JSON 先通过 schema/适配函数进入类型化模型；不要凭感觉增加字段或默认业务规则。
- 每个请求传递 AbortSignal；新查询使旧结果失效；401 刷新单飞且最多重试一次。
- 用户输入、富文本、URL、iframe 和 postMessage 都是不可信边界；禁止不可信 Vue 模板。
- 不把密钥放入 `VITE_*`；锁文件入库；依赖变更说明版本、用途和风险。
- 交互优先原生语义元素，保证键盘焦点、label、错误播报和减少动画。
